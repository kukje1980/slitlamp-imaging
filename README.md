# 슬릿램프 디지털 영상 시스템 (Slit-Lamp Imaging)

안과 슬릿램프(세극등 현미경)에 연결된 **HDMI 캡처 장비(UVC 웹캠으로 인식, 예: 에버미디어)** 의
실시간 영상을 받아 **사진 캡처 · 일시정지 · 동영상(mp4) 녹화**를 하고, 각 영상물을
**환자 데이터베이스에 연결 저장**함과 동시에 **지정한 폴더에도 저장**하는 진료실용
네이티브 데스크탑 앱입니다. 단일 PC에서 오프라인으로 동작합니다.

- 화면 좌측: 실시간 영상 + 컨트롤(안구 선택 / 일시정지 / 사진 캡처 / 녹화) — 캡처 '찰칵' · 정지영상 · 녹화 효과음
- 화면 우측: 선택한 환자의 캡처 사진을 작은 썸네일 세로줄로(최신이 위) 표시, 클릭 시 크게 보기
- 상단: 아이콘 메뉴 — **홈 | 촬영 | Pro 검토 | 검사 기록 | 신규 환자 | 정보 수정** 과 카메라·단축키·설정·**테마 전환**(설정에 저장), 그 아래 환자 요약과 검색/선택
- **홈(시작) 화면**: 큰 아이콘 타일(신규 환자·환자 목록·촬영·Pro 검토·검사 기록·설정)로 바로 가기. "다음부터 촬영 화면으로 바로 시작"을 켜면 건너뜀(`start_screen`)
- **검사 기록**: 촬영일별 목록 → 그날의 영상 모음 + **검사 소견**(검사 종류 서식, 칸을 벗어나면 자동 저장) + 환자 정보. 인쇄/PDF 보고서에 소견이 함께 들어감
- 생년월일은 **달력에서 선택**하거나 숫자만 입력(`19800315`, 주민번호 앞자리 `800315`, `1980.3.15`)하면 자동으로 정리됩니다
- 전용 앱 아이콘(`assets/icons/app.ico`) — 실행파일·바로가기·설치 마법사에 적용

> 동일 기능의 **웹 버전**(FastAPI, 브라우저에서 사용)은 `web/` 폴더에 있습니다 (v0.2 스마트 캡처·분석 탭 포함). 데스크탑 앱과
> 웹 앱 두 가지 버전을 모두 제공합니다. 웹 버전은 MedFix 처럼 **Render/Vercel 에 올려 인터넷 주소로** 쓸 수 있습니다
> (`render.yaml`, `web/vercel.json` — 방법은 `web/README.md` 의 "인터넷 주소로 쓰기").

## 기술 스택
- Python 3.11+, **PySide6**(Qt6), **OpenCV**(opencv-python), **SQLite**(stdlib)
- v0.2: **스마트 캡처**(초점 판정·Best Shot·자동 정지/저장·포커스 피킹·화질 점검) · **분석**(조명 태그·형광 면적·충혈 지수·경과 비교) — 아래 참조
- 동영상: **imageio-ffmpeg**(번들 ffmpeg, H.264/yuv420p) 우선, 실패 시 `cv2.VideoWriter(mp4v)` 폴백
- 대상 OS: **Windows**(캡처: DirectShow) · **macOS 11 이상**(캡처: AVFoundation, Apple Silicon·Intel). 개발/CI는 Linux에서 합성·파일 소스로 가능

같은 소스로 맥에서도 동작합니다. 캡처 장비는 맥에서 자동으로 **AVFoundation** 백엔드로 열리고,
데이터는 `~/Library/Application Support/SlitLampImaging/` 에 저장됩니다.

### 방법 1 — 설치용 dmg 만들기 (권장)
1. 맥에 **Python 3.11 이상** 설치 ([python.org](https://www.python.org/downloads/macos/) 설치본 권장 — 맥 기본 python3 는 3.9 인 경우가 많음)
2. 터미널에서 저장소 폴더로 이동 후 `./build_mac.sh`
3. `dist/SlitLampImaging-<버전>-mac-<arm64|x86_64>.dmg` 를 열고 앱을 **Applications** 로 끌어다 놓기

> 맥이 없어도 GitHub **Actions → "Build macOS app" → Run workflow** 로 Apple Silicon(arm64)·Intel(x86_64)용
> dmg 를 각각 만들 수 있습니다(실행 결과 화면의 *Artifacts* 에서 내려받기).

### 방법 2 — 소스에서 바로 실행
Finder 에서 `run_mac.command` 더블클릭(처음 한 번 자동 설치). 하드웨어 없이 확인: 터미널에서 `./run_mac.command --source synthetic`

### 처음 실행할 때 (보안 · 권한)
- 앱은 Apple 개발자 인증서로 서명·공증되지 않았으므로, 처음에는 **앱 아이콘을 Control-클릭(우클릭) → 열기 → 열기**로 실행합니다.
  (macOS 15 이상: 한 번 실행 시도 후 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**)
- **카메라 권한** 요청이 뜨면 **허용**. 거부했다면 *시스템 설정 → 개인정보 보호 및 보안 → 카메라*에서 켠 뒤
  상단 **카메라 재연결**을 누르세요(소스 실행 시에는 '터미널'에 권한을 줍니다).
- 단축키는 맥 관례대로 Ctrl 대신 **⌘(Command)** 를 씁니다(⌘Z 실행 취소, ⌘Y 다시 실행). 촬영/Pro 전환은 F2(fn+F2).

## 소니 카메라 (ZV-E10 II · FX3 — MicroREC Ultra 등)
소니 카메라의 **USB 스트리밍**(UVC) 기능으로 **USB 케이블 하나**에 웹캠처럼 연결합니다. 캡처보드·드라이버가 필요 없습니다.

2. 같은 메뉴의 **USB 스트리밍 출력 해상도/프레임** → **4K(2160p)** 또는 **HD(1080p)**

4. 프로그램이 소니 카메라를 **자동으로 찾아 선택**합니다 (목록에 ★ 표시)

> 카메라 자체 셔터로 고해상도 원본(2,400만 화소)을 찍는 **원격 제어**는 소니 Camera Remote SDK 로 데스크탑 앱에 추가할 예정입니다

## Smart Capture (데스크탑 앱)
초점이 맞는 순간을 놓치지 않게 돕는 촬영 보조 기능입니다. 영상 아래 **Smart** 도구줄에서 켭니다.
분석은 별도 스레드에서 축소 영상(폭 640)으로 하므로 실시간 화면이 끊기지 않고, **저장되는 사진은 항상 보정하지 않은 원본 프레임**입니다
(피킹 색·ROI 테두리 등은 화면 표시용이며 저장되지 않음).

| 기능 | 동작 |
|------|------|
| **자동 정지** (Smart Freeze) | 슬릿램프를 움직여 초점을 맞추면 가장 선명했던 프레임에서 화면을 자동 정지 → 확인 후 **사진 캡처**로 저장하거나 **라이브**로 복귀. 4분할에서는 현재 칸을 채움 |
| **자동 저장** (Auto Snapshot) | 같은 조건에서 가장 선명한 프레임을 바로 저장 (메모: `Smart 자동 저장 (초점 N)`). 쿨다운(기본 2.5초) + 초점을 한 번 벗어났다가 다시 맞춰야 다음 저장 → 파일이 쏟아지지 않음 |
| **Best Shot** | 사진 캡처를 누르면 최근 0.6초 중 가장 선명한 프레임을 저장 (버튼을 누르는 사이의 흔들림 보정) |
| **포커스 피킹** | 초점이 맞은 미세 구조를 색으로 표시. 감도 슬라이더로 조절, 반사광 테두리는 제외 |
| **ROI** | 초점을 볼 영역(각막·홍채·수정체 등)을 영상 위에서 끌어 지정. 영상을 두 번 클릭하면 중앙 60% 로 초기화 |
| **품질 표시** | 초점 · 노출 · 안정(흔들림) · 반사 점수와 안내 문구 (예: "반사광 — 조명 각도를 조절하세요") |

동작 원리 (`app/capture/smart_capture.py`):
1. ROI 안에서 **Tenengrad(Sobel)** 선명도를 계산. 포화된 반사광과 그 날카로운 테두리, 어두운 배경은 제외
2. 선명도는 장면마다 크기가 다르므로 **최근 최고값 대비 %** 로 판정 (기본 85% 이상 = 초점 맞음)
3. 노출(밝은 부분 기준) · 반사광 비율 · 프레임 간 흔들림이 기준을 넘으면 그 프레임은 후보에서 제외
4. 최근 1초 프레임을 버퍼(메모리 상한 200MB)에 두고, 선명도가 **정점을 지나 떨어지거나** 정점 근처에 **잠시 머무르면**
   버퍼에서 가장 선명한 프레임을 고름 — 셔터를 그때 누르는 것보다 정확
5. 가만히 있는 장면은 다시 찍지 않음 (초점이 한 번 벗어났다가 돌아와야 다음 자동 촬영)

점수는 같은 촬영 조건에서 비교하는 **상대값**이지 절대적인 화질 지표가 아닙니다. 설정값은 `config.json` 의 `smart_*`
항목에 저장됩니다 (`smart_ready_pct` 초점 판정 기준 %, `smart_cooldown_s` 자동 저장 간격, `smart_peaking_color` red/green/yellow/cyan).

## AI 에이전트 에디션
촬영 화면 아래 **에이전트** 도구줄이 추가된 별도 프로그램입니다 (`SlitLampAgent`, 데이터 폴더 `%APPDATA%\SlitLampAgent`).
기본 에디션에서도 **설정 → AI 에이전트** 를 켜면 같은 기능을 쓸 수 있습니다. 모든 처리는 PC 안에서만 일어나며 인터넷을 쓰지 않습니다.

| 기능 | 설명 |
|------|------|
| **장면 인식** | 지금 화면이 확산광 전안부 / 슬릿 단면 / 후방조명 / 형광염색(코발트) / 적외선 마이봄 / 외안부·안검 / 판독 불가 중 무엇인지 매 프레임 판정 (슬릿이면 폭·각도도 추정). 규칙 기반이 기본이고, 학습 모델(`assets/models/scene_model.json` 또는 `.onnx`)이 있으면 우선 사용 |
| **자동 촬영** | 장면이 1초 이상 안정되고 Smart Capture 의 초점·흔들림 조건이 맞으면 **눈·장면당 한 장**을 자동 저장. 왜 찍었는지(장면·초점·안정 시간)가 상태줄과 로그에 남음 |
| **프로토콜 체크리스트** | 기본 전안부 / 백내장 / 건성안·각막 / 마이봄샘 / 자유 촬영. 필요한 샷(장면 × 눈)이 찍힐 때마다 ✓, 다음에 찍을 샷을 안내. 환자가 바뀌면 새로 시작 |
| **촬영 전후 클립** | 최근 8초 프레임을 메모리(JPEG)에 두고, 사진을 찍는 순간(수동·자동) **앞 4초 + 뒤 2초**를 mp4 로 환자 영상에 함께 저장 (설정에서 끌 수 있음) |
| **추천 프레임** | 같은 전후 구간에서 초점 점수가 높은 프레임 4장을 썸네일로 제시 — 클릭하면 사진으로 저장. 선택/닫기 기록이 '좋은 사진' 학습 라벨이 됨 |
| **사용 데이터 수집** | 촬영·자동 촬영·추천 선택/거부·정지·녹화·설정 변경 등을 **익명 세션 ID** 로 기록 (환자 정보 없음). `<앱데이터>/agent/events/*.jsonl` + DB `agent_events` |
| **학습 데이터 내보내기** | 에이전트 메뉴 → 캡처 사진을 장면 라벨 폴더(환자 정보 없음, 파일명은 내용 해시)와 `manifest.csv` 로 내보내 재학습에 사용 |

**학습 (인터넷 공개 데이터 → 병원 데이터)**: `tools/agent_train/DATASETS.md` 참고.
```bash
pip install scikit-learn
python tools/agent_train/train_scene.py --data <라벨별 폴더>          # → assets/models/scene_model.json
python tools/agent_train/train_scene.py --data <공개 데이터> --data <병원 내보내기 폴더>   # 재학습
```
학습 결과(JSON)는 앱이 numpy 만으로 추론하므로 추가 설치가 없습니다. 수천 장이 모이면 `train_cnn_onnx.py` 로 CNN(ONNX) 도 만들 수 있습니다.

실행·빌드: `python run.py --edition agent`, Windows `set SLITLAMP_BUILD_EDITION=agent && pyinstaller build.spec` + `installer\agent.iss`,
맥 `./build_mac.sh agent`. GitHub Release 에는 `SlitLampAgent-Setup-<버전>.exe` 와 `SlitLampAgent-<버전>-mac-*.dmg` 가 함께 올라갑니다.

> 에이전트는 **촬영 보조**(언제·무엇을 찍을지, 어떤 프레임이 선명한지)만 하며 진단이나 소견을 내지 않습니다.

규칙 기반 영상처리로 구한 **참고 지표**입니다(학습된 AI 모델 아님). 결과는 영상 위 오버레이로 보여 주고,
의사가 확인한 뒤 **코멘트에 추가** 또는 **결과 영상 저장**(오버레이·주석 합성, 원본 보존)으로 남깁니다. 분석은 보정 전 원본 픽셀로 합니다.

| 분석 | 결과 | 비고 |
|------|------|------|
| **영상 품질** | 선명도(Tenengrad)·노출·반사광 비율, 판정(흐림/반사광/노출 부족) | |

## 스마트 캡처 (Pro LIVE · v0.2) — 초점이 맞는 순간을 놓치지 않게
슬릿램프는 양손이 조이스틱·슬릿 조절에 묶여 있어, 프로그램이 **초점이 맞는 순간을 알아서 잡아주는** 것이 체감 가치가 가장 큽니다.
Pro 화면 사이드 패널 **스마트** 탭에서 설정하며, 모두 `config.json` 에 저장됩니다. 하드웨어 교체 없이 HDMI/USB 영상만으로 동작합니다.

| 기능 | 설명 |
|------|------|
| **초점 판정** | 화면 중앙 **관심 영역**(점선, 20~100% 조절)의 선명도(Tenengrad)를 매 프레임 계산. 포화된 반사광·암부는 제외해 슬릿광 경계에 속지 않음. 영상 위에 `초점 92` 처럼 **최근 최고점 대비 상대값**으로 표시 |
| **Best Shot** | 최근 약 1초의 프레임을 메모리에 보관하다가 **CAPTURE**(Space·풋스위치)를 누르면 그중 **가장 선명한 프레임**으로 정지 → 누르는 순간의 흔들림·셔터 지연이 사라짐. 깜빡임 구간 프레임은 제외. (기본 켜짐, 끄면 현재 프레임) |
| **Smart Freeze** | 초점이 흐렸다가 최고점(90% 이상) 근처에서 연속 6프레임 안정되면 **자동 정지**. 확인 후 SAVE 또는 RESUME. 1.5초 쿨다운 |
| **Auto Save** | 같은 조건에서 자동으로 환자 DB 저장(코멘트 `자동 촬영`). 파일이 쌓이지 않게 3초 쿨다운 |
| **촬영 금지 조건** | 눈 깜빡임(밝기 급변 후 0.3초) · 반사광 과다 · 노출 부족 · 흔들림 · 정지 화면(초점을 맞춰 들어온 흔적이 없음) |
| **포커스 피킹** | 초점이 맞은 경계를 빨강/초록/시안으로 표시(민감도 3단계). 반사광 주변 제외. **표시 전용** — 정지·저장 영상에는 들어가지 않음 |
| **실시간 화질 점검** | 초점 · 노출 · 안정 · 반사 0~100 과 재촬영 안내("반사광/노출 과다 — 조명 각도·밝기 조절" 등). 진단이 아닌 **사진 품질** 정보 |

> 점수는 절대값이 아니라 같은 조명·배율 안에서 비교하는 상대값입니다. 엔진은 Qt 와 분리된 독립 모듈(`app/capture/smart_capture.py`)이라
> 웹 버전·다른 카메라 경로에도 붙일 수 있습니다. 720p 기준 프레임당 약 4 ms(CPU).

## 분석 (Pro · 측정 보조) — 진단이 아닌 "측정값 · 기록 보조"
Pro 사이드 패널 **분석** 탭. 학습 모델 없이 OpenCV 영상처리만 쓰며, **질환 판정·정상/비정상 문구를 내지 않습니다**
(식약처 디지털의료기기 SW 대상이 되지 않도록 "측정값 제공·기록 보조"로 한정). 결과 레이어는 표시 전용이며 저장본에 들어가지 않습니다.

| 기능 | 화면 | 설명 |
|------|------|------|
| **조명 모드 태그** | 1화면 | 디퓨즈 / 슬릿 / 코발트블루(형광) / IR·흑백 을 색 분포로 추정. 코멘트 기록 시 `[코발트블루(형광)]` 태그가 함께 저장 |
| **형광 염색 면적** | 1화면 | 코발트블루+플루오레세인 영상에서 녹색 형광 화소의 **면적·비율**. 편집 탭 **원** 주석을 그리면 그 영역만 측정, 눈금 보정 시 **mm²** |
| **충혈 지수** | 1화면 | 측정 영역의 붉은 기(0~100)와 혈관 화소 비율 — 같은 조건의 경과 영상끼리 비교하는 **상대값** (등급 판정 아님) |
| **코멘트에 기록** | 1화면 | 마지막 측정 결과를 영상 코멘트에 추가(`[슬릿] 형광 염색 면적 3.2% (측정 영역), 1.40 mm²`) |
| **백내장 혼탁 지수** | 1화면 · LIVE | 핵(슬릿)·피질(역조명) 지수, 촬영 조건 메모, LOCS III 입력, 경과 그래프, LIVE 가이드 — 아래 참조 |
| **고스트 겹치기** | 비교 | 왼쪽(이전) 영상을 오른쪽(현재) 위에 반투명(0~100%)으로 겹쳐 변화 확인 |
| **위치 정렬** | 비교 | 이전 영상을 현재 영상에 맞춰 이동·회전(ECC) — 촬영 위치 차이 보정 |
| **깜빡임 전환** | 비교 | 두 영상을 0.5초마다 번갈아 표시 — 변화한 부위가 눈에 띔 |

> 조명·배율·각도가 다른 영상의 차이는 병변 변화로 해석하지 마세요. 재촬영 때는 고스트 겹치기로 같은 위치에서 찍는 것이 비교의 핵심입니다.

### 백내장 — 수정체 혼탁 지수 (분석 탭 · 등급 판정 없음)
LOCS III 같은 표준 등급표가 있고 "혼탁도 = 숫자"가 이미 측정 기능으로 자리 잡은 영역이라 첫 임상 측정 기능으로 넣었습니다.
**"3등급 백내장"이 아니라 "핵 혼탁 지수 62 (지난 검사 대비 +8)"** 로만 표현합니다. — `app/capture/cataract.py`

| 기능 | 설명 |
|------|------|
| **핵 혼탁 (슬릿)** | 슬릿 단면 사진에서 밝은 세로 띠를 찾아 **가장 좁은 띠 = 각막**, **가장 넓은 띠 = 수정체**. 수정체 띠 밝기 ÷ 각막 띠 밝기 → 0~100. 각막을 기준자로 삼아 조명 밝기가 달라도 비율이 유지되고, 포화 화소(정반사)는 제외. 각막 띠가 없으면 "절대 밝기 참고값"으로 표시 |
| **피질 혼탁 (역조명)** | 편집 탭 **원**으로 동공을 표시 → 동공 안 주변보다 어두운 얼룩 면적 % (가장자리 띠 제외). **동공 직경**(px·mm) 함께 기록, 5 mm 미만이면 "산동 부족 → 참고용" |
| **촬영 조건 메모** | 슬릿 폭·각도·배율·노출을 기록해 두면 다음 검사 **LIVE 가이드**에 "지난 검사: …" 로 표시 (같은 조건 재촬영이 지수 비교의 생명) |
| **LOCS III 입력** | 의사가 NO/NC/C/P 1~6 을 입력하면 지수와 함께 `measurements` 테이블에 저장 → 나중에 등급 추정 모델의 **라벨 데이터**로 축적 (표시에는 쓰지 않음) |
| **경과 그래프** | 같은 환자·같은 안구의 핵(보라)·피질(빨강) 지수 추이, 측정 시 "지난 검사 대비 ±" |
| **LIVE 촬영 가이드** | 백내장 모드: 화면 중앙 슬릿 위치 띠 + 45° 안내 + 지난 검사 조건 |

> `cataract.py` 상단 상수(RATIO_CLEAR/DENSE, DARK_FRAC 등)는 합성 영상으로 잡은 초기값입니다. 실제 슬릿램프 사진 30장 정도로
> 의사 체감과 맞는지 확인해 조정하세요. 등급 자동 추정(2단계)은 라벨이 500~1,000장 쌓인 뒤 허가 전략과 함께 검토합니다.

## 질환별 샘플 사진 (가져오기)
교육·데모용 참고 사진을 **질환별 '샘플' 환자**로 등록합니다. 사진은 저장소·설치파일에 들어 있지 않고(대부분 CC BY-NC-ND — 비영리·변경 금지),
각 PC에서 받아 둔 폴더를 한 번 가져옵니다.

1. 샘플 사진 폴더(또는 zip)를 받아 둡니다 — 질환별 하위 폴더 + `metadata.json` (예: `일반외래_슬릿램프_질환순/01_건성안/...`)
2. 상단 **샘플** 버튼 → 폴더 선택 (또는 `python -m app --import-samples <폴더|zip>`, zip 도 가능)
3. 환자 목록에 `샘플 · 건성안 (SAMPLE-01)` 처럼 질환마다 환자가 생기고, 사진이 그 환자의 영상으로 보입니다.

- 사진은 **원본 그대로** 복사합니다(색·크기·워터마크 변경 없음). 원문 진단·출처·라이선스는 영상 코멘트에, 저해상도·외상 여부도 코멘트 첫 줄에 표시됩니다.
- 등급(LOCS 등)은 붙이지 않습니다. 진단은 각 사진 원문 기준이며 실제 환자가 아닙니다.
- 다시 가져와도 이미 등록된 사진은 건너뛰고, `metadata.json` 의 SHA-256 과 다른 파일은 등록하지 않습니다.
- 사진 목록·라이선스: [`docs/SAMPLE_PHOTOS.md`](docs/SAMPLE_PHOTOS.md), `sample_images/external_outpatient_catalog.csv`

## 동영상 화질 (일반 / 고화질)
**설정 → 동영상 화질**에서 고릅니다 (윈도우·맥 앱은 `config.json` 의 `video_quality`, 웹은 브라우저에 기억).

| 모드 | 윈도우·맥 앱 (H.264) | 웹 (브라우저 녹화) | 용도 |
|------|------|------|------|
| **일반** (기본) | CRF 23 | 1080p 약 5Mbps · 4K 약 20Mbps | 가볍고 파일이 작음 — 기록용 |
| **고화질** | CRF 18 (원본과 눈으로 구분이 어려운 수준) | 1080p 약 12Mbps · 4K 약 50Mbps | 세밀한 관찰·발표용, 파일 약 2~2.5배 |

두 모드 모두 실시간(30fps)으로 녹화되도록 해상도에 맞는 인코더 속도를 씁니다 (1080p `veryfast`, 4K `ultrafast`).
4코어 2.1GHz PC 에서 4K 5초 녹화: 두 모드 모두 150장 중 150장 기록·정지 후 0.2초 안에 마무리
(예전 설정 medium·CRF 10 은 같은 PC 에서 84장을 버리고 마무리에 13.6초).

## 설정 / 저장 위치
설정 파일과 기본 데이터는 사용자 앱데이터 폴더에 저장됩니다.
- Windows: `%APPDATA%\SlitLampImaging\`
- macOS: `~/Library/Application Support/SlitLampImaging/`
- 기타(개발): `~/.local/share/SlitLampImaging/`

`config.json` 주요 항목: `camera_index`, `source_mode`(device|file|synthetic),
`capture_width/height`, `photo_format`(png|jpg), `media_root`(기본 저장),
`export_root`(동시 저장 폴더), `db_path`, `subfolder_template`, `sounds_enabled`(효과음),
`camera_props`(카메라 속성 — Explorer 판), `report_per_page`, `slideshow_seconds`.

저장 경로 규칙(기본): `<root>/<차트번호>_<환자ID>/YYYY-MM-DD/<HHMMSS>_<OD|OS|NA>.<확장자>`
(`export_root`에도 동일 구조로 복사)

앱 실행 후 상단 **설정** 버튼에서 카메라 인덱스, 해상도, 저장 폴더를 변경할 수 있습니다.

## 데이터베이스
SQLite 테이블:
- `patients`: 차트번호, 환자ID, 이름, 생년월일, 성별, 연락처, 메모, 증상, 진단명, 담당의
- `captures`: 환자FK, 종류(photo/video), 파일경로, export경로, 썸네일경로, 촬영시각, 안구, 길이(ms), 코멘트, 검사FK
- `measurements` (v0.2): 환자FK, 영상FK, 안구, 종류(nuclear/cortical/…), 지수, 상세(JSON), **LOCS 의사 입력(JSON)**, 촬영 조건, 측정시각
- `exam_notes`: 검사 기록 화면의 환자별·촬영일별 소견
- `exams` (Explorer 판): 환자FK, 검사일, 검사명, 진단·소견, 병력 메모 (캡처 시 그날 검사 자동 생성, 하루 여러 검사 가능)
- `ref_images` (Explorer 판): 참조 영상 라이브러리 (파일·썸네일 경로, 분류, 제목, 설명, 원본 캡처 id)

환자 삭제 시 `ON DELETE CASCADE`로 캡처 레코드도 함께 삭제됩니다(디스크 파일은 보존).

### 데이터 안전 장치
- **자동 백업**: 실행할 때마다 하루 한 번 `backups/slitlamp-YYYYMMDD.db` 사본을 남깁니다(최근 14일 보관,
  SQLite online backup API 로 사용 중에도 일관된 사본). 복구는 프로그램을 종료한 뒤 `slitlamp.db` 를 백업 파일로 바꿔 넣으면 됩니다.
- **손상 감지**: 시작 시 `quick_check` 를 실행해 손상된 파일이면 원본을 건드리지 않고 경로·백업 폴더를 안내한 뒤 종료합니다.
- **트랜잭션**: 모든 쓰기는 실패 시 롤백되어 반쯤 기록된 상태가 남지 않습니다. WAL + `synchronous=FULL` 로 정전·강제 종료에도
  커밋된 레코드는 보존되며, 종료 시 WAL 을 본 파일에 합칩니다(checkpoint).
- **잠금 대기**: 다른 프로그램(DB 뷰어 등)이 잠시 잠가도 10초까지 기다립니다. 프로그램 자체는 **한 번만 실행**됩니다
  (두 번 실행하면 안내 후 종료 — 카메라·DB 동시 사용 방지).
- **영상 파일**: 사진은 메모리에서 인코딩한 뒤 임시 파일→이름 바꾸기로 저장해 깨진 파일이 남지 않고 한글 경로에서도 안전합니다.
  같은 밀리초에 두 장이 저장되어도 덮어쓰지 않습니다. 동영상은 **인코더가 파일을 완전히 닫은 뒤에만** export 복사·DB 기록을 합니다.
- **디스크 공간**: 사진 50MB·녹화 500MB 미만이면 저장을 거부하고 알리며, 2GB 미만이면 시작 시 경고합니다.
- **카메라 끊김**: 실제 장비가 끊기면 녹화 중이던 부분을 저장하고 2→3→5→8→12초 간격으로 자동 재연결을 시도합니다.
- **오류 기록**: 처리되지 않은 예외는 `logs/app.log` 에 남고(exe 빌드에서도) 사용자에게 한 번 알린 뒤 프로그램은 계속 실행됩니다.

## Windows 설치파일(Setup.exe) 만들기 — 일반 프로그램처럼 설치/제거
설치 마법사가 있는 `Setup.exe`를 만들어 시작메뉴/바탕화면 바로가기 등록과 제거(프로그램 추가/제거)를 지원합니다.

**준비:** [Inno Setup 6](https://jrsoftware.org/isdl.php) 설치 (무료)

**원클릭 빌드 (권장):** repo 루트에서 `build_installer.bat` 더블클릭 또는 실행
```bat
build_installer.bat
```
→ 의존성 설치 → PyInstaller 번들 → Inno Setup 컴파일을 한 번에 수행하고
`dist\installer\SlitLampImaging-Setup-0.2.0.exe` 가 생성됩니다.

**수동 빌드:**
```bat
pyinstaller --noconfirm build.spec
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\slitlamp.iss
```

생성된 `Setup.exe`를 클리닉 PC에서 실행하면 설치 마법사가 뜹니다.
- 기본은 **관리자 권한 없이 사용자 폴더에 설치**되며, 마법사에서 "모든 사용자(관리자)" 설치도 선택할 수 있습니다.
- 프로그램 파일과 무관하게 환자 DB·이미지는 항상 `%APPDATA%\SlitLampImaging\` 에 저장되므로, 재설치/업데이트해도 데이터는 보존됩니다.
- 설치 항목 구성: 설치 경로/제거는 `installer\slitlamp.iss`, 표시 이름·버전·게시자는 파일 상단 `#define` 값에서 수정.
