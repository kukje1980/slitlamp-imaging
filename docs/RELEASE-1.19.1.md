# SlitLamp v1.19.1

**선택한 사진을 지우는 기능이 들어갔습니다** (윈도우 · 맥 앱, 웹 모두).

- **Pro 검토 → 삭제 버튼 (Delete 키)**: MULTI 에서 클릭해 선택한 영상(최대 2장) 또는 1화면에 열려 있는 영상을 지웁니다.
  지울 대상이 없으면 버튼이 꺼지고, 확인 창에서 '예' 를 눌러야 지워집니다.
  - 지운 뒤 1화면은 다음 영상이 같은 자리에 보이고, 마지막 영상을 지웠으면 그 앞 영상으로 갑니다. 촬영 화면 썸네일 · 검사 기록도 함께 갱신됩니다.
  - 웹 Pro 화면도 같은 버튼 · 같은 키입니다. 참조(샘플) 사진은 삭제 대상에서 빠집니다.
- **촬영 화면 썸네일 보기 창 → 삭제 버튼 (Delete)**: 썸네일을 눌러 큰 화면으로 연 사진 · 동영상 한 건을 지웁니다. 웹 보기 창도 같습니다.
- 지워지는 것: DB 기록 + 기본 저장 파일 + 썸네일. **지정 폴더(export)에 복사된 사본은 백업으로 남겨 둡니다** (Explorer 판의 삭제와 같은 규칙).
  웹은 서버 저장 · '이 PC에만 저장' 모두 파일과 기록을 지웁니다.

다운로드
- Windows: SlitLampImaging-Setup-1.19.1.exe (기본), KeelerSlitLamp-Setup-1.19.1.exe (Keeler), SlitLampAgent-Setup-1.19.1.exe (AI 에이전트) 등.
- Mac: 각 판 arm64(Apple Silicon) · x86_64(Intel) DMG.
- 기존 데이터는 그대로 사용합니다.
