# SlitLamp v1.19.2

**그날 촬영한 사진을 한 번에 모두 지우는 기능이 들어갔습니다** (윈도우 · 맥 앱, 웹 모두).

- **촬영 화면 썸네일 → 촬영일 제목 줄 오른쪽 쓰레기통**: 그 날짜에 촬영한 사진 · 동영상을 모두 삭제합니다.
  필터(OD · OS)를 걸어 둔 상태라도 그 날 전체가 대상입니다. 확인 창에 사진 · 동영상 수가 표시되고 '예' 를 눌러야 지워집니다.
- **검사 기록 화면 → '날짜 삭제' 버튼**: 왼쪽 목록에서 고른 촬영일의 영상을 모두 삭제합니다.
- **웹 썸네일 목록**의 날짜 줄에도 같은 쓰레기통 버튼이 있습니다 (서버 저장 · '이 PC에만 저장' 모두).
- 지워지는 것: DB 기록 + 기본 저장 파일 + 썸네일. **지정 폴더(export) 사본과 그 날의 검사 소견은 남겨 둡니다.**
  지운 뒤 썸네일 · Pro 검토 · 검사 기록 목록이 함께 갱신됩니다.

v1.19.1 의 개별 삭제(Pro '삭제' · 보기 창 '삭제', Delete 키)도 그대로 들어 있습니다.

다운로드
- Windows: SlitLampImaging-Setup-1.19.2.exe (기본), KeelerSlitLamp-Setup-1.19.2.exe (Keeler), SlitLampAgent-Setup-1.19.2.exe (AI 에이전트) 등.
- Mac: 각 판 arm64(Apple Silicon) · x86_64(Intel) DMG.
- 기존 데이터는 그대로 사용합니다.
