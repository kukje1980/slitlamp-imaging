# SlitLamp v1.20.0

상단 질환 아이콘으로 참조 사진을 바로 꺼내 멀티로 비교하고, 찍은 사진을 큰 화면으로 바로 확인하는 판입니다. 그 밖의 기능은 v1.19.2 와 같습니다.

- **상단 질환 아이콘 줄**: 상단바 환자 검색 오른쪽 빈 공간에 질환별 작은 아이콘(설치판 샘플 11개 질환 + 등록한 참조 분류).
  누르면 아래 **참조 줄**이 열리며 그 질환의 샘플 · 참조 사진이 작은 사진으로 나오고, 그 중 최대 4장이 지금 환자 사진과 함께 **멀티 화면**에 놓입니다.
  오른쪽 목록에서 고른 환자 사진이 없으면 가장 최근 사진을 자동으로 고릅니다. 참조 줄에서 사진을 더 고르거나 뺄 수 있고, 같은 아이콘을 다시 누르면 그 질환 사진을 뺍니다.
  창이 좁으면 '질환 ▾' 메뉴 버튼 하나로 줄어듭니다.
- **멀티 화면 오른쪽 메뉴(보정 · 편집 · 분석) 접기**: 기본으로 접혀 있어 사진이 넓게 보이고, 가는 손잡이(‹ ›)를 누르면 펴집니다. 마지막 상태를 기억합니다.
- **촬영 직후 큰 화면 보기**: 사진을 찍으면 그 사진이 창 최대화로 바로 뜹니다(돋보기 · 이동 · 맞춤 · 삭제 그대로).
  **다시 촬영**(Enter · Esc) 을 누르면 촬영 화면으로 돌아오고, 촬영 단축키(기본 C) 나 슬릿램프 USB 버튼을 누르면 창을 닫고 바로 다시 찍습니다.
  설정 → 일반 → '촬영 후 보기' 에서 끌 수 있습니다. 전체 화면 촬영 중에는 뜨지 않습니다.
- 웹 버전: 촬영 직후 큰 화면 보기('다시 촬영' · 촬영 키로 바로 다시 찍기, 설정 '촬영 후 보기')가 같이 들어갔습니다. 질환 아이콘 줄 · 멀티 메뉴 접기는 윈도우 · 맥 앱에만 있습니다.

기존 데이터 · 설정은 그대로 씁니다.
