# SlitLamp v1.20.0 최종 통합판

10월 30일까지 두 저장소와 여러 작업 브랜치에 나뉘어 있던 변경을 **모두 하나로 합친 최종판**입니다.
새 저장소 `kukje1980/slitlamp-imaging` 의 v1.19.0(안전 수정 · 동영상 화질 · 컴퓨터 사양)과, 옛 저장소 `kukje1980/Image-capture` 에
같은 번호로 나간 v1.19.0 ~ v1.19.2(샘플 사진 기본 포함 · 사진 삭제) 및 배포 전이던 v1.20.0(질환 아이콘 · 촬영 직후 큰 화면)을 모두 담았고,
아직 어디에도 들어가지 않았던 **외장 하드 백업 · 효과음 크기 조절 · USB 버튼 진단 도구 · 큰 촬영 목록 나눠 그리기**를 더했습니다.

## 새로 합친 기능
- **외장 하드 · 다른 드라이브 백업** (설정 → 백업): 저장 즉시(실시간) · 켤 때 · 주기적 · 수동으로 새 파일 · 바뀐 파일만 복사합니다.
  백업 폴더 이름은 시작 날짜 + 마지막 날짜(예: `210908261028`)이고, 환자 기록 DB 는 쓰는 중에도 일관된 사본과 날짜별 사본(60일)을 남깁니다.
  외장 하드를 뺐다 다시 꽂으면 전체 확인, 녹화 중인 파일은 끝난 뒤 복사, 상태줄 백업 버튼으로 상태를 봅니다. 원본은 읽기만 합니다.
- **효과음 크기 조절** (설정 → 일반 → 효과음 크기 0~100 % · 들어보기): 윈도우 · 맥 앱과 웹 모두.
- **촬영 목록 나눠 그리기**: 사진이 수천 장인 환자를 골라도 처음 120장만 그리고 '이전 N장 더 보기' 로 이어 봅니다 (화면 멈춤 방지).
- **USB 버튼 보드 진단 도구** (`tools/usb_buttons_probe.py`): 슬릿램프 USB 버튼의 HID · 시리얼 신호를 보고 새 장치를 찾습니다.

## v1.20.0 화면 기능
상단 질환 아이콘으로 참조 사진을 바로 꺼내 멀티로 비교하고, 찍은 사진을 큰 화면으로 바로 확인하는 판입니다. 

- **상단 질환 아이콘 줄**: 상단바 환자 검색 오른쪽 빈 공간에 질환별 작은 아이콘(설치판 샘플 11개 질환 + 등록한 참조 분류).
  누르면 아래 **참조 줄**이 열리며 그 질환의 샘플 · 참조 사진이 작은 사진으로 나오고, 그 중 최대 4장이 지금 환자 사진과 함께 **멀티 화면**에 놓입니다.
  오른쪽 목록에서 고른 환자 사진이 없으면 가장 최근 사진을 자동으로 고릅니다. 참조 줄에서 사진을 더 고르거나 뺄 수 있고, 같은 아이콘을 다시 누르면 그 질환 사진을 뺍니다.
  창이 좁으면 '질환 ▾' 메뉴 버튼 하나로 줄어듭니다.
- **멀티 화면 오른쪽 메뉴(보정 · 편집 · 분석) 접기**: 기본으로 접혀 있어 사진이 넓게 보이고, 가는 손잡이(‹ ›)를 누르면 펴집니다. 마지막 상태를 기억합니다.
- **촬영 직후 큰 화면 보기**: 사진을 찍으면 그 사진이 창 최대화로 바로 뜹니다(돋보기 · 이동 · 맞춤 · 삭제 그대로).
  **다시 촬영**(Enter · Esc) 을 누르면 촬영 화면으로 돌아오고, 촬영 단축키(기본 C) 나 슬릿램프 USB 버튼을 누르면 창을 닫고 바로 다시 찍습니다.
  설정 → 일반 → '촬영 후 보기' 에서 끌 수 있습니다. 전체 화면 촬영 중에는 뜨지 않습니다.
- 웹 버전: 촬영 직후 큰 화면 보기('다시 촬영' · 촬영 키로 바로 다시 찍기, 설정 '촬영 후 보기')가 같이 들어갔습니다. 질환 아이콘 줄 · 멀티 메뉴 접기는 윈도우 · 맥 앱에만 있습니다.

기존 데이터 · 설정은 그대로 씁니다.
