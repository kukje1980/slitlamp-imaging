# SlitLamp v1.20.2

현장에서 써 보며 요청한 **촬영 화면 사용성 개선**입니다 (윈도우 · 맥 앱).

## 오른쪽 사진 목록: 오른쪽 클릭 = 전송 · 삭제 · 멀티
- 사진 위에서 **마우스 오른쪽 클릭**하면 그 자리에 **전송 · 삭제 · 멀티** 메뉴가 뜹니다. 그 사진을 아직 안 골랐으면 골라 주고,
  여러 장을 골라 두었으면 **고른 사진 전체**에 적용됩니다 (메뉴 맨 위에 'N장 선택').
  - **전송**: 설정한 전송 방법(폴더 · 클라우드 · PACS)으로 보냅니다 (촬영 도크 '전송' 과 같음).
  - **삭제**: 확인 창을 거쳐 고른 사진 · 동영상을 지웁니다 (지정 폴더 사본은 남김). 멀티 화면 중이면 닫고 지웁니다.
  - **멀티**: 고른 사진을 한 화면에 모아 봅니다.
- 오른쪽 사진 목록 위(OD · OS 위)의 **'멀티' 버튼은 없앴습니다.** 멀티 화면은 촬영 도크의 **'초기화'** 로 닫습니다.
- **설정 → 일반 → '사진 오른쪽 클릭'** 에서 고릅니다: **메뉴(전송 · 삭제 · 멀티)** (기본) 또는 **멀티 화면 바로**(예전처럼 오른쪽 클릭하자마자 멀티).
  라이브 영상 위 오른쪽 클릭(고른 사진으로 멀티)은 그대로입니다.
- **설정 → 일반 → '메뉴 항목'** 에서 메뉴에 넣을 항목을 고릅니다: **전송 · 전송(삭제) · 멀티 · 삭제** (기본: 전송 · 멀티 · 삭제).
  **전송(삭제)** 는 보낸 뒤 이 PC 에서 지웁니다 — 모두 보냈을 때만, 확인 창을 거쳐서 (오류 · 건너뜀이 있으면 지우지 않음).

## OD 는 오른쪽 · OS 는 왼쪽, 크게
- 사진 목록 썸네일의 눈 표시를 **OD(우안)는 오른쪽 위, OS(좌안)는 왼쪽 위**에 약 1.5배 크게 굵게 표시합니다 (선택 번호는 OD 표시 옆).
- 사진 목록 필터(전체 · OS · OD)와 촬영 도크의 눈 고르기(OS · OD · —)도 같은 순서입니다. 단축키(1 = OD · 2 = OS)는 그대로입니다.

## 상단 질환 아이콘: 이름 표시 · 마우스를 올리면 사진 미리보기
- 아이콘 아래에 **질환 이름**(정상 · 건성안 · 안검염 · 결막염 · 백내장 · 다래끼 · 결막출혈 · 익상편 · 찰과상 · 각막염 · 후낭혼탁)이 보입니다.
- 아이콘에 **마우스를 올리면** 바로 아래에 그 질환의 **사진이 작게(최대 4장)** 전체 질환 이름 · 사진 수와 함께 뜹니다.
- 창 폭에 맞춰 세 단계로 바뀝니다: 넓으면 아이콘 + 이름(1920 화면), 조금 좁으면 아이콘만(마우스를 올리면 이름 · 사진),
  더 좁으면 '질환 ▾' 메뉴 하나. 예전보다 좁은 창에서 메뉴로 접히는 일은 없습니다.

## 촬영 직후 큰 화면에도 질환별 샘플 아이콘
- 사진을 찍으면 뜨는 큰 화면 위쪽에 상단 메뉴와 같은 **질환별 샘플 아이콘**(이름 · 마우스를 올리면 사진)이 있습니다.
- 질환을 누르면 창이 닫히고 **방금 찍은 사진과 그 질환 샘플 사진이 멀티 화면에 나란히** 놓입니다.

## 오른쪽 사진 목록 썸네일을 선명하게
- 썸네일 파일을 120px → **480px** 로 만들고, 화면 배율(맥 레티나 2배 등)에 맞춰 그립니다. 예전에는 작은 썸네일을 4배 가까이 늘려 흐렸습니다.
- 이미 찍어 둔 사진(작은 썸네일)은 먼저 그대로 보이고, **뒤에서(별도 스레드) 원본으로 선명한 썸네일을 한 번 다시 만들어** 그 자리에서 바꿔 그립니다.
  썸네일 파일도 새로 저장되므로 다음부터는 처음부터 선명합니다. 메모리는 최근 본 250장까지만 둡니다.

## 상단 환자 선택 드롭다운 없앰
- 상단바 '환자 검색' 옆의 **환자 선택 드롭다운을 없앴습니다** (샘플 환자까지 길게 늘어서던 목록).
- **환자 검색** 칸에 이름 · 차트번호 · 연락처를 치면 바로 아래에 결과가 뜨고, 누르거나 **Enter**(첫 결과)로 고릅니다.
  지금 환자는 검색 칸에 흐린 글씨로 '환자: 이름 (차트번호)' 로 보입니다. 전체 목록은 '환자 목록' 화면에서 봅니다.
- 검색어를 치기만 해서는 환자가 바뀌지 않습니다 (고를 때만 바뀜 — 다른 환자로 찍히는 일 방지).

## 설정 → 일반 → '실시간 멀티화면'
- 켜면 오른쪽 사진 목록에서 사진을 **왼쪽 클릭으로 고르는 즉시 가운데가 멀티 화면**이 되고, 더 고르면 칸이 늘어납니다.
  다시 눌러 다 빼면 라이브 화면으로 돌아갑니다. 기본은 꺼짐(예전처럼 고르기만).

## 켜자마자 좌우(OD)가 골라져 있음
- 프로그램을 켜면 **OD(우안)가 미리 골라져** 있습니다 (촬영 도크에 '기본 OD'). 예전에는 '미확인' 이라 슬릿램프를 좌우로 한 번
  움직여야 골라졌습니다. 슬릿램프 좌우 신호가 오면 그 눈으로 바로 바뀌고, OD · OS 를 직접 골라도 됩니다.
- 시작 눈은 설정 파일(config.json)의 `start_eye` 로 바꿀 수 있습니다: `"OD"`(기본) · `"OS"` · `"NA"`(예전처럼 미확인).
- 주의: 신호가 오기 전 첫 사진은 OD 로 저장됩니다 — 왼눈부터 찍을 때는 OS 를 먼저 누르거나 슬릿램프를 움직여 신호를 받으세요.

## 릴리스 전 점검에서 찾아 고친 것
- **사진이 많은 환자를 처음 열 때 화면 멈춤(최대 약 6초)**: 선명한 썸네일을 원본에서 바로 읽게 했더니, 기본 저장 형식인 PNG 는 줄여 읽기가 안 돼
  1장 약 50ms × 120장 = 약 6초 멈췄습니다 → 뒤에서 만들도록 바꿔 0.2초 안에 열리고(120장 기준), 1.5초 안에 모두 선명해집니다.
- **상단바 폭을 잘못 재서 글자가 겹칠 수 있던 문제**: 질환 이름을 넣으며 확인해 보니, 상단바가 접혔다 펴질 때 바뀌기 전 크기로 폭을 재
  (실제 1861px → 1201px 로 잼) 1700 · 1800px 창에서 이름이 들어갈 자리가 없는데도 켜졌습니다 → 두 폭(이름 포함 · 아이콘만)을 상태를 바꿔 직접 잽니다.
- **질환 이름 잘림**: '결막하출혈' · '각막찰과상' 이 '결…혈' 처럼 잘려 4글자 이내 짧은 이름(결막출혈 · 찰과상)으로, 전체 이름은 미리보기에.
