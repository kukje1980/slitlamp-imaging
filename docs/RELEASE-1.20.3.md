# SlitLamp v1.20.3

현장에서 요청한 **촬영 화면 정리 · 촬영 직후 바로 전송**입니다 (윈도우 · 맥 앱).

## Pro 검토 화면 입구 없앰
- 상단 **'Pro 검토' 버튼**, 홈 화면의 **'Pro 검토' 타일**, 검사 기록 화면의 **'Pro 검토' 버튼**, 단축키 **F2(촬영 ↔ Pro 검토)** 를 모두 없앴습니다.
  상단 화면 버튼은 **홈 · 촬영 · 검사 기록 · 환자 목록** 넷입니다.
- 보정 · 필터 · 편집 · 스마트 · 분석 · 정밀 분석 같은 **Pro 기능은 멀티 화면 안에 그대로** 있습니다 (오른쪽 ‹ › 손잡이로 메뉴 펴기).
- 단축키 설정 창에서도 'F2 촬영 ↔ Pro 검토' 줄은 보이지 않습니다. 저장해 둔 값은 지우지 않습니다 (Explorer 판은 F2 = 라이브 ↔ 영상 전환으로 그대로 씀).
  슬릿램프 USB 버튼에 F2 를 지정해도 더 이상 '단축키와 겹친다' 고 막지 않습니다.

## 아래쪽 참조 줄 없앰
- 멀티 화면 아래의 **참조 줄('N장 고름 · 빼기 · 라이브러리…')** 과 촬영 도크의 **'참조' 버튼**을 없앴습니다.
- 참조 사진은 **상단 질환 아이콘**으로 고르고 뺍니다: 누르면 그 질환 샘플(최대 4장)이 환자 사진 옆에 멀티 화면으로 놓이고, 다시 누르면 뺍니다.
- **참조 영상 라이브러리**(등록 · 정보 수정 · 샘플 사진 · 지금 환자 사진과 비교)는 **설정 → 맨 위 '참조 영상 라이브러리'** 버튼으로 엽니다
  (설정 창을 닫고 라이브러리가 열립니다 — 설정에서 바꾼 값이 있으면 먼저 '확인').
- 예전 설정 파일에 '참조 줄 보이기'(ref_bar_visible)가 켜져 있어도 보이지 않습니다.

## 촬영 직후 화면 · 멀티 화면에서 캡처 = 초기화
- 사진을 찍은 직후 큰 화면이나 멀티 화면에서 **캡처(촬영 도크 셔터 · 촬영 단축키 C · 슬릿램프 USB 사진 버튼)** 를 누르면
  **초기화**됩니다: 큰 화면 · 멀티 화면을 닫고, 고른 사진 · 참조 사진 · 질환 아이콘 · 정지 화면을 비워 **라이브 촬영 화면**으로 돌아갑니다.
  이때 사진은 찍지 않습니다 — 한 번 더 누르면 그때 찍습니다.
- **설정 → 일반 → '보기 · 멀티 화면에서 캡처'** 에서 **초기화(기본)** 또는 **바로 촬영**(예전처럼 곧바로 다시 찍기)을 고릅니다.
- USB 녹화 · 스틸 버튼은 예전과 같습니다 (큰 화면을 닫고 그 동작). Smart 자동 저장 · AI 에이전트 자동 촬영은 영향 없습니다.

## 촬영 직후 큰 화면에서 바로 전송
- 사진을 찍으면 뜨는 큰 화면 아래쪽에 **'전송'** · **'전송(삭제)'** 버튼이 생겼습니다 — **그 사진 1장**을 설정한 방법(폴더 · 클라우드 · PACS)으로 보냅니다.
  - **전송**: 보낸 뒤 창은 그대로이고 버튼 옆에 '✓ 보냄' 이 표시됩니다.
  - **전송(삭제)**: 모두 보냈을 때만 확인 창을 거쳐 이 PC 에서 지우고 창을 닫습니다 (오류 · 건너뜀이 있으면 지우지 않음). 오른쪽 사진 목록도 바로 갱신됩니다.
- 멀티 화면에서는 촬영 도크의 **'전송'** 으로 오른쪽 목록에서 고른 사진을 보냅니다 (그대로).

## 릴리스 전 점검에서 찾아 고친 것
- **USB 사진 버튼으로 큰 화면을 닫은 직후 누름이 버려질 수 있던 문제**: 큰 화면을 닫으면 맥 · 윈도우에서 메인 창이 조금 늦게 앞으로 오는데,
  그 사이 '다른 창이 앞에 있음' 으로 판단해 초기화도 촬영도 하지 않을 수 있었습니다 → 큰 화면을 닫은 그 누름이면 화면 검사보다 먼저 초기화합니다.
- **좌우 신호가 큰 화면을 닫은 뒤 첫 사진이 초기화로 바뀌던 문제**: 슬릿램프 좌우 신호(F6/F7)로 큰 화면이 닫힌 뒤 2초 안에 사진 버튼을 누르면
  라이브 화면인데도 초기화됐습니다 → '방금 닫음' 표시를 모든 USB 버튼에서 바로 지웁니다.
- **큰 화면에서 보낼 때 환자 정보**: 큰 화면이 떠 있는 동안 다른 환자로 바꾸면 새 환자 이름 · 차트번호로 보낼 수 있었습니다(PACS) → 그 사진의 환자로 보냅니다.
- **참조 영상 라이브러리가 메인 창 뒤에 열릴 수 있던 문제(맥)**: 설정 창을 닫고 열 때 맨 앞으로 올립니다.
- **Explorer 판 설정 창**: 쓰지 않는 '참조 영상 라이브러리'(꺼진 버튼) · '보기 · 멀티 화면에서 캡처' 를 숨겼습니다 (Explorer 판은 메뉴에 라이브러리가 따로 있음).
