### 설정 창 다시 분류 · 설명 화면

- 설정 창을 **왼쪽 메뉴 + 오른쪽 화면**으로 바꾸고 분류를 다시 나눴습니다:
  도움말(**설정 안내**) · 화면과 촬영(화면 · 소리 / 촬영 / 사진 목록 · 멀티) · 장비 연결(카메라 / 촬영 모드 / 단축키 · USB 버튼) ·
  사진 관리(저장 · 삭제 / 전송 / 백업) · 그 밖에(참조 · 샘플 / AI 에이전트 / 컴퓨터 사양).
- 화면마다 제목 · 한 줄 설명, 항목마다 아래 회색 글씨로 **무엇을 하는 설정인지 쉬운 말로** 적었습니다 (주의할 점은 주황 글씨).
- 새 **설정 안내** 화면: '이럴 땐 여기를 보세요'(예: 카메라 화면이 안 나와요 → 카메라)와 '메뉴 한눈에 보기' — 누르면 그 화면으로 갑니다.
- 바로 실행 버튼은 관련 화면으로 옮김: 카메라 다시 연결 → 카메라, 단축키 설정 → 단축키 · USB 버튼, 샘플 사진 가져오기 · 참조 영상 라이브러리 → 참조 · 샘플.
- '영상 받는 곳'(예전 소스 모드 device / file / synthetic) · 사진 형식(PNG / JPG)을 알기 쉬운 이름으로, 시험용 동영상 파일 칸은
  '동영상 파일 재생' 을 골랐을 때만 보이고 '파일 선택' 버튼을 붙였습니다. 저장 · 삭제 화면에 기본 저장 폴더(보기 · '폴더 열기')를 보입니다.
- 설정 값 · 저장 형식은 그대로입니다 (예전 탭 이름으로 여는 곳도 새 화면으로 열림).

### 프로그램을 끌 때 촬영 사진 지우기 (설정 → 저장 · 삭제)

- '프로그램을 끌 때 촬영 사진 · 동영상 지우기' 를 켜면, 프로그램을 끌 때 **몇 장을 지울지 알려 주는 안내 창**이 나옵니다:
  **삭제하고 종료** · **남기고 종료**(기본 버튼 — Enter 를 잘못 눌러도 지우지 않음) · **취소**(Esc — 끄지 않고 돌아감). 기본은 꺼짐.
- 지울 범위: 모든 환자의 사진 · 동영상(샘플 사진 제외, 기본) / 오늘 촬영한 것 / 이번에 프로그램을 켠 뒤 촬영한 것.
- 지우는 규칙은 기존 삭제와 같습니다: DB 기록 · 기본 저장 파일 · 썸네일을 지우고, 비게 된 환자 · 날짜 폴더도 치웁니다.
  환자 정보 · 검사 소견 · 샘플 사진 · 참조 영상 라이브러리, 함께 저장할 폴더(export)의 사본, 외장 하드 백업은 남깁니다.
- 녹화 중이면 녹화를 마무리해 저장한 뒤, 백업 '닫을 때 마무리' 가 켜져 있으면 백업을 마친 뒤에 지웁니다. 많으면 진행 창('멈추기' 가능).
- 촬영 프로그램(표준판)에만 있습니다 (Explorer 판 설정에는 보이지 않음).

### 상단 질환 아이콘 미리보기에서 사진 고르기

- 질환 아이콘에 마우스를 올리면 뜨는 사진 미리보기로 **마우스를 옮겨도 닫히지 않고**, 사진을 누르면 **그 사진만 멀티 화면에 넣기 ·
  다시 누르면 빼기** (지금 환자 사진을 고르지 않았으면 가장 최근 사진과 같이). 고른 사진은 노란 테두리 · ✓ 로 보입니다.
- 미리보기는 최대 8장(한 줄 4장). 아이콘을 누르면 예전처럼 앞의 4장을 한 번에 놓습니다. 한 번에 한 질환 — 다른 질환 사진을 고르면 앞 질환 사진은 빠집니다.
- 촬영 직후 큰 화면의 질환 아이콘 미리보기에서 사진을 누르면 창을 닫고 방금 찍은 사진과 그 사진을 멀티 화면에 나란히 놓습니다.
